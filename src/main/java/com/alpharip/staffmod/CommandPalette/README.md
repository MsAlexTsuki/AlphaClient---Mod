# AlphaClient Command Palette

Open the searchable action palette with the **P** key in a world or with:

```text
/palette
```

Search available AlphaClient module toggles and common screens. Use the up/down arrows and Enter, or click an entry. Press Escape to close the palette. Module actions are listed only when the module is implemented and the current account has access. Module changes use AlphaClient's existing permission and profile persistence APIs.

The palette includes shortcuts to the AlphaClient home menu, General modules, Quality settings, HUD editor, help, Waypoints, waypoint display settings, and Staff Operations. Staff Operations still enforces its existing account permission check.

This first implementation is client-side. Search text is temporary and is not saved. The key can be rebound in Minecraft Controls under the AlphaClient category.
