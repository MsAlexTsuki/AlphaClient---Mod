# Pet Memorial Prototype

A permanent-style log model for pets that have died.

## Included
- Memorial records for pet name, species, owner, world, cause, and timestamp.
- A book that retains all records in order.
- A formatter for a short memorial inscription.
- Recorder API intended for a future tamed-pet death listener.

## Not included / not verified
- No automatic detection of tamed-pet deaths is wired yet.
- Pet identity/deduplication and the exact death-cause mapping still need implementation.
- No memorial GUI, book item, or disk persistence.
- No AlphaClient Core integration.
- Forge compilation and in-game behavior have not been tested.
