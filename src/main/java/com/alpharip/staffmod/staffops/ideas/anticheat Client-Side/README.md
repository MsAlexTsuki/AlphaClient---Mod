# Anticheat Client-Side

Deze map groepeert bestaande Java-ideeën die mogelijk bruikbaar zijn voor client-side anticheat in Minecraft 1.8.9.

De bestanden zijn hierheen verplaatst voor overzicht; hun implementatie is niet uitgebreid of gewijzigd. De aanwezigheid van een analyzer betekent niet automatisch dat deze live Minecraft-events uitleest of betrouwbaar cheats detecteert. Integratie, metingen, beoordeling en validatie moeten per onderdeel nog worden gecontroleerd.

Categorieën omvatten Reach, autoclick/click timing, aim/rotatie, combat, movement, packets/ping en detectieondersteuning.
