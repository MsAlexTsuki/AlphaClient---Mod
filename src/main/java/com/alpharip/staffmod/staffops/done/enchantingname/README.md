# Enchanting Name

## Idea

Display the actual enchantment name directly in the Minecraft enchanting table, so the player can see what enchantment an option offers without hovering over that option.

## Scope

- Show the enchantment name directly in the enchanting table.
- Do not require the player to hover over an enchantment option to identify it.

## Status

Idea only. No implementation or runtime behavior has been added yet.
